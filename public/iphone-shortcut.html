Send to BidLens

iPhone Safari cannot make a PWA a Share Sheet target. Build this Apple Shortcut instead.

  1. In Shortcuts tap +, rename it Send to BidLens, open ⓘ, enable Show in Share Sheet, accept Images, and set unavailable input to Ask for Photo.
  2. Add Convert Image: Shortcut Input to JPEG, preserve quality, strip metadata when offered.
  3. Add Get Contents of URL: https://YOUR-BIDLENS-API.onrender.com/api/mobile-import, POST, Form, key image, value Converted Image.
  4. Add Get Dictionary Value for openUrl, then Open URLs.
