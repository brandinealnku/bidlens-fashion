# Architecture

Next.js App Router renders the responsive dashboard and guided analysis. Provider-neutral auction, AI, and comparable adapters isolate external access. Deterministic integer-cent finance, similarity, quality, scoring, and valuation modules never delegate arithmetic to AI. Prisma provides normalized ownership relations; demo authentication resolves to one seeded reseller while production authentication is designed for server-side Supabase session resolution. Jobs can be stored with `QUEUED`, `RUNNING`, `SUCCEEDED`, `FAILED`, or `NEEDS_REVIEW` and executed inline locally.

`lib/services/workflow.ts` is the transactional application-service boundary used by `/api/workflow`. It derives the current user centrally, checks listing ownership, records audit events, and persists each derived result. `/api/uploads` delegates bytes to the local image-storage adapter and stores only image metadata in Prisma.
